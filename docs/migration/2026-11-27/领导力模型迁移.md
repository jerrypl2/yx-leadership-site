# 领导力模型迁移

本次落实[原清单](./悦心官网内容与功能迁移清单.xlsx)「迁移决策」第 14 行。Version 0.4 的结论保留在[当时的核对记录](./Version-0.4优先迁移核对.md)。专题放在「组织能力地图 → 管理者与组织领导力」，「课程咨询目录」搜索框上方另设「按领导力模型选课」。两个入口共用[领导力模型专题](https://www.amachina-yuexin.com/capability-map/leadership-model/)。

四个维度、十二个方面以及原课名对应关系来自[旧站领导力模型](https://www.amachina.com/course/leadership.aspx)。行为说明按原意重新整理。每个方面配一个用于说明行为的工作示例。课程编号和现主名与[首批业务内容台账](./第三阶段业务内容发布台账.md)核对。

| 维度 | 方面及课程去向 |
| --- | --- |
| 凝聚人心 | 领导对应课程 19。影响对应课程 22、115。促发对应课程 4。 |
| 发展能力 | 选才显示历史课程示例「Tango：企业无形资产经营模拟」并可咨询。育人对应课程 6、120。自我领导显示「领导者的内在觉察力」并可咨询。 |
| 经营企业 | 经营意识显示「财务1-2-3」并可咨询。战略目光对应课程 117。思维与创新对应课程 10、125。 |
| 管理运营 | 执行与绩效对应课程 31。流程与质量显示「流程管理的5大旋律」并可咨询。文化与价值显示「领导方阵实验室」并可咨询。 |

7 个方面衔接 10 门已发布的咨询课程，课程详情继续指向待教务确认的班次。其余 5 个方面各举一门原模型对应课程，并预填包含方面及课名的咨询留言。

在仓库根目录运行 `npm run build`、`npm run check` 和 `npm run test:sites` 可检查静态导出、锚点和课程去向。运行 `node scripts/check-business-browser.mjs --live` 可在桌面及手机视口复核两个入口、四个维度导航、育人到班次咨询和待确认课程的留言预填。
