# 第一阶段 · 联系我们

官网由 GitHub Pages 提供联系页。现有 Sites API 把姓名、邮箱、公司、电话、微信和留言保存到私有 D1 表 `contact_messages`，成功后才向访客显示编号。公开接口不能按编号读取留言。无法确认保存时保留输入，同一标签页内原样重试沿用原编号。

## 收件和回复

负责人邮箱是 `info@amachina.com`。经确认，官网使用 FormSubmit 转发访客的姓名、邮箱、留言和编号。访客可以在表单上看到转发说明。FormSubmit 保留转发记录 30 天，通知邮件的回复地址为访客填写的邮箱。公司、电话和微信保存在站点数据库。负责人也可通过已授权的 Sites 后台，在「悦悦 · 官网对话服务」的 `DB → contact_messages` 查看 `payload`，从业务邮箱直接联系访客。

首次使用需要负责人在收件箱或垃圾邮件中找到 FormSubmit 的通知，核对官网域名后点击「Activate Form」。服务商已在激活请求中返回“激活邮件已发送”。负责人尚无法打开邮箱，实际到件和回信留待核验。激活后，用可读取的访客邮箱在官网提交一条留言，在负责人收件箱按编号查找，点击回复，再到访客邮箱核对回信。保存后的回执也提供“用自己的邮箱发送这条留言”的入口。

## 投递状态

| 数据库状态 | 值班处理 |
| --- | --- |
| `pending` | 已保存，等待转发。GitHub Actions 每十五分钟触发检查，单次最多十条。遇到服务商限流则留在队列，遵守退避时间。GitHub 工作流只接收数量。 |
| `activation` | 服务商要求激活。其帮助说明表示激活后会释放此前暂存的留言。后续留言先保留本站，六小时后有待发记录时再次检查激活情况。 |
| `sent` | 服务商已受理，可用主题中的编号核对目标收件箱。 |
| `review` | 服务商回执不确定，或投递中途发生中断。负责人按编号核对收件箱和服务商记录，必要时从数据库中的访客邮箱直接回复，避免重复发信。 |

工作流和后台共用加密 Secret `CONTACT_RETRY_TOKEN`。仓库变量 `CONTACT_MAIL_ENABLED=true` 启用定时检查。也可手动运行「Retry contact notifications」。工作流不会向 GitHub 输出姓名、邮箱或留言内容。

## 验收记录

| 场景 | 生产实测或自动化证据 |
| --- | --- |
| 桌面提交与双击 | Chromium，1440 × 900。在正式站双击发送只发出一个 POST，随后重放请求仍返回同一编号。首次测试编号 `63eeb647-c98a-407e-9eff-b0eddcbb9ed3`，已从私有库核对一条。 |
| 手机提交与故障重试 | Chromium 的 iPhone 13 触屏视口，390 × 664。正式后台已保存后人为丢弃回执，页面保留原留言。点重试复用编号，再次重放仍只有一条。首次测试编号 `dffe045e-3367-41e1-923e-6088e9736cae`。 |
| 表单校验与保存失败 | 自动化测试覆盖无效邮箱、超限和存储失败，确认这些请求无法得到保存成功回执。 |
| 通知与重复投递 | 自动化验证收件人、Reply-To、最小转发字段、并发重复、429 后重试成功、待激活队列释放及回执丢失后的人工核对。 |
| 邮箱验收 | 已请求激活，负责人暂时无法进入收件箱。实际收到通知及访客收到回复仍待验收。 |

在仓库根目录执行 `npm ci`、`npm run build`、`npm run check`、`npm run test:sites`。实测正式站可先运行 `npx playwright install chromium`，再运行 `CONTACT_ACCEPTANCE_LIVE=1 node scripts/check-contact-browser.mjs`。命令会写入两条标记为验收的生产留言。请使用返回的编号，从私有数据库核对行数。

更新后台代码时，在本站仓库根目录运行 `node scripts/prepare-api.mjs <现有 Sites API 检出目录>`。在对应 Sites 项目执行 `bash scripts/build.sh` 和 `node scripts/validate-artifact.mjs`，通过 Sites 发布源码及对应构建。GitHub Pages 发布负责前端。

服务商的激活和暂存规则见 [FormSubmit 帮助](https://formsubmit.co/help)。邮件回复及字段规则见 [FormSubmit 文档](https://formsubmit.co/documentation)。
