## 验收入口

课程目录可用新旧名称检索。每门课保留一个稳定主网址，连接参考班次咨询及能力方向。企业方案链接到工作方法、已有案例和预填咨询主题的联系表单。发布工作流照常读取线上版本并检查部署后的首页，本批预计从 0.2 升至 0.3。

数据核对依据为同目录《悦心官网分阶段迁移实施计划》的课程、班次、案例顾问与资源工作表，以及上文逐项记录的源页。

验收命令为 `npm run build`、`npm run check` 与 `npm run test:sites`。在 4183 端口启动本地预览后，`node scripts/check-business-browser.mjs` 验证桌面及手机视口的别名检索、课程到班次、案例到方案和五个咨询主题。添加 `--live` 可在正式站重复验证，不向业务后台写入测试留言。
