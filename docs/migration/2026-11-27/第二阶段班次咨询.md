# 悦心教室 · 公开课班次咨询

按 11 月 27 日教务交接口径，12 月的 15 个候选班次统一标记为「待教务确认」，仅开放咨询。参考城市、日期、课程编号和班次编号来自本目录内实施计划的「12月班次交接」。旧标价、可用名额和报名截止时间均未确认。正式录取、席位和旧站已付学员的承接由教务另行核定。

官网入口为 `/classroom/`，例如 `/classroom/?session=8161` 可直接打开深圳班的咨询单。访客可筛选城市，填写姓名、回复邮箱及选填问题，保存后可下载带编号和参考日期的回执。手机或桌面都使用同一接口，重复提交沿用原编号。咨询不占用席位。

教务可在现有私有后台 `DB → contact_messages` 按回执编号查询。咨询记录包含 `kind=classroom_inquiry` 和原始班次快照。官网共用已配置的负责人通知队列，通知主题为「悦心教室班次咨询」和编号。服务商待激活或限流期间，可直接查库回复。真实学员资料只存放在业务后台和获准使用的通知渠道。

首页版本随 GitHub Pages 发布自动递增。工作流读取正式首页当前版本，在本次构建中统一写入静态首页和浏览器程序，并在部署后校验公开首页。发布流程串行执行，生产版本读取失败会暂停该次发布。本次从 0.1 升至 0.2；下次成功更新后应显示 0.3。

本机浏览器验收覆盖桌面 1440 × 900 和手机触屏模拟 390 × 664，检查城市筛选、选班、重复点击、提交成功后丢失回执再重试，以及回执文件中的课程与编号。可在项目根目录运行 `npm run check` 与 `npm run test:sites`。预览服务器位于 4179 端口时运行 `node scripts/check-classroom-browser.mjs`；使用 `CLASSROOM_ACCEPTANCE_LIVE=1` 会在生产库生成两条标记为验收的咨询。
