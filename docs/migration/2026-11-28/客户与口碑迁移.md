## 验收

- 桌面和手机可从「关于我们」、案例页、行业页和全站页脚进入专题。
- 区分中文、英文、行业命中与无匹配四种搜索场景，清除后恢复完整 14 组。折叠名录在静态 HTML 中也可展开。
- 9 个课程链接均直达对应反馈，固定页头下可读，且可返回专题。无可核实评价的课程维持原有结构。
- 用 `npm run build`、`npm run check` 和 `npm run test:sites` 核对静态导出、子路径部署和既有功能。构建产物在本机 4183 端口运行时可执行 `node scripts/check-customers-browser.mjs`，部署后以 `--live` 验证正式域名。
